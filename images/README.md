# Images: where each one goes

Upload a file with the exact name below into this `images/` folder. It appears on the site automatically. Until then, the site shows a built-in placeholder. Search the HTML for "IMAGE:" to find each spot.

| File name | Where it shows | Size / shape |
|---|---|---|
| logo.png | Logo mark beside the AEXION SYSTEMS text in the header | ~150 px |
| favicon.ico | Browser tab icon | 16-48 px |
| hero.jpg | Background behind the big home page heading (subject on the right side) | 2400 x 1350 |
| office.jpg | Big photo next to "Spend your day on customers, not computers" | 1600 x 1600 |
| console.png | Replaces the example ticket/alert feed in the "Powered by Atera" section (blur client names) | 1200 x 900 |
| m365.jpg | Photo above the M365 Check-Up checklist | 1600 x 1066 |
| network-illustration.jpg | Illustration in the Services page heading | 1400 x 930 |
| workstations.jpg | Workstation packages graphic on the Services page | 1774 x 887 |
| work-1.jpg | "Recent work" gallery, wide photo | 1600 x 1000 |
| work-2.jpg | "Recent work" gallery, tall photo | 1000 x 1250 |
| work-3.jpg | "Recent work" gallery, tall photo | 1000 x 1250 |

Text you can edit (not images):
- The small ticket + "office status" cards in the heading: `index.html`, search "HEADING EXAMPLE CARDS".
- The example alert rows: `index.html`, search "TICKETING / ALERTS EXAMPLE".
- Dark section backgrounds (circuit grid + glow): `styles.css`, search "BACKGROUND: dark sections".

How to upload on GitHub: open the repo, go into the `images` folder, click **Add file → Upload files**, drag the files in, then click **Commit changes**. The site updates in about a minute.
